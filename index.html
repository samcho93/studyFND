FND 카운터 만들기Java 메서드와 클래스로 만드는 디지털 회로
    시작하기

    숫자 하나가 FND에 켜지기까지

    디지털 시계 속 숫자는 카운터(7490) → 디코더(7446) → FND 순서로 신호가 흘러가며 만들어집니다. 이 강좌에서는 각 칩이 하는 일을 Java 메서드 하나씩으로 만들고, 서로 연결해 0 ~ 9를 세는 카운터를 콘솔에 출력합니다. 마지막에는 카운터 두 개를 이어 시계의 기본인 100진·60진 카운터를 만듭니다.

    전체 흐름

    입력int 7
    →
    Step 1 · 6cnvtDec2Bin / ttl7490
    →
    4비트{1,1,1,0}
    →
    Step 2ttl7446
    →
    7비트{1,1,1,0,0,1,0}
    →
    Step 3makeFnd
    →
    콘솔char[5][5]

    하드웨어로 보면 이런 회로입니다. 오른쪽 FND는 Step 2의 결과인 7비트 값으로 그린 모양입니다.

    Step 1

    10진수를 4비트 배열로 바꾸기

    FND 회로의 모든 칩은 0과 1만 주고받습니다. 첫 단계에서는 10진수 하나를 받아 네 개의 비트를 배열에 담아 돌려주는 메서드를 만듭니다.

    • 나머지(%)와 몫(/)으로 2진수 구하기
    • 배열 인덱스와 비트 자리의 관계
    • 배열을 반환하는 메서드
    static int[] cnvtDec2Bin(int num)

    원리: 2로 나눈 나머지가 비트

    10진수를 2로 계속 나누면, 매번 나오는 나머지가 낮은 자리부터 차례로 2진수의 비트가 됩니다. 4비트면 네 번만 나누면 됩니다.

    직접 해보기num = 0 ~ 15
    결과 (MSB → LSB)
    반환 배열
    배열 순서에 주의하세요. out[0]에는 가장 낮은 자리(2⁰), out[3]에는 가장 높은 자리(2³)가 들어갑니다. 그래서 6(0110)을 배열 그대로 출력하면 {0,1,1,0}, 5(0101)는 {1,0,1,0}처럼 거꾸로 보입니다. 7490 칩의 출력 핀 QA~QD 순서와 같습니다.

    코드

    cnvtDec2BinBit은 같은 일을 비트 연산으로 합니다. num & 0x01은 맨 오른쪽 비트만 남기고, num >>= 1은 한 칸 오른쪽으로 밀어 다음 비트를 꺼낼 준비를 합니다. 결과는 두 메서드가 같습니다.

    확인 문제

    cnvtDec2Bin(9)가 반환하는 배열은?
    {1,0,0,1} — 9 = 8 + 1 이므로 out[0]과 out[3]이 1입니다.
    num에 16을 넣으면 어떻게 될까요?
    네 번만 나누므로 {0,0,0,0}이 됩니다. 5번째 비트(16의 자리)는 버려집니다. 4비트로 표현할 수 있는 범위는 0 ~ 15입니다.
    반복문 안에서 num = num / 2를 빼먹으면?
    num이 바뀌지 않아 네 칸 모두 같은 값(num % 2)이 들어갑니다. 예: 6 → {0,0,0,0}, 7 → {1,1,1,1}.

    연습 과제

    2. 반대로 4비트 배열을 받아 10진수를 돌려주는 int cnvtBin2Dec(int[] bin)을 만드세요. (Step 2에서 사용합니다)
    3. 비트 수를 매개변수로 받는 int[] cnvtDec2Bin(int num, int size)로 확장해 보세요.
    Step 2

    4비트를 FND 세그먼트 신호로 바꾸기

    FND는 막대 7개(a ~ g)의 LED로 숫자를 만듭니다. 4비트 값을 보고 어떤 막대를 켤지 정해 주는 칩이 BCD-7세그먼트 디코더 7446이고, 이번 단계에서 이 칩을 메서드로 만듭니다.

    • 세그먼트 a ~ g의 위치
    • 2차원 배열로 만든 진리표
    • 가중치 8·4·2·1로 인덱스 구하기
    static int[] ttl7446(int[] bin) // 반환: {a, b, c, d, e, f, g}

    세그먼트 이름과 진리표

    위에서부터 시계 방향으로 a, b, c, d, e, f, 가운데가 g입니다. 숫자 0 ~ 9마다 켜야 할 세그먼트를 표로 만들어 두고, 4비트 값을 10진수로 바꾼 뒤 그 행을 꺼내면 됩니다.

    직접 해보기비트를 눌러서 바꿔 보세요
    입력 bin (MSB → LSB)
    인덱스 계산 반환 배열 {a,b,c,d,e,f,g}
    실제 7446과의 차이. 실제 74LS46/47은 출력이 0일 때 세그먼트가 켜지는 Active-Low 칩(Common Anode FND용)입니다. 이 강좌에서는 이해하기 쉽도록 1 = 켜짐으로 통일했습니다. (Active-High인 7448과 같은 동작)

    코드

    참고 코드의 원래 버전은 return table[num];만 있어서 10 ~ 15가 들어오면 ArrayIndexOutOfBoundsException이 발생합니다. 여기서는 if (num > 9) return new int[7];로 모든 세그먼트를 끄도록 막았습니다. new int[7]은 0으로 채워진 배열입니다.

    확인 문제

    bin = {0,1,1,0} 일 때 num은?
    0×8 + 1×4 + 1×2 + 0×1 = 6 입니다. bin[3]이 MSB라는 점을 기억하세요.
    숫자 1에서 켜지는 세그먼트는?
    b, c — 오른쪽 세로 막대 두 개입니다. 표의 {0,1,1,0,0,0,0}.
    return table[num];이 반환하는 배열을 밖에서 바꾸면 어떤 일이 생길까요?
    table은 메서드가 호출될 때마다 새로 만들어지므로 다음 호출에는 영향이 없습니다. 하지만 table을 static 필드로 옮기면 원본 표가 바뀌는 버그가 생깁니다. 그럴 땐 table[num].clone()을 반환하세요.

    연습 과제

    1. 10 ~ 15일 때 16진수 A ~ F 모양이 나오도록 표를 16행으로 늘려 보세요. (A: a,b,c,e,f,g)
    2. Active-Low 버전 ttl7446Low(int[] bin)을 만들어 0과 1을 뒤집어 반환해 보세요.
